# Dinety

Dinety is a free rhythm game.

---

## Introduction

Dinety is separated into **Plot Mode** and **Single Mode**.

You can solve puzzles using the clues provided to advance the game’s storyline and unlock the corresponding songs in **Plot Mode**. It revolves around Dinety's plot, which is about dimensions and the universe.

We will be including a wide variety of songs, as well as tracks taken from other games, in **Single Mode**, and we will do our utmost to make the note charts as engaging as possible.

## Technology Stack

- Language: GDScript
- Engine: Godot 4.7.2
- UI: Godot Control Nodes
- Audio: AudioStreamPlayer / AudioServer
- Data Storage: JSON / ConfigFile
- Build & Export: Godot Export Templates
- Version Control: Git + GitHub
- Platforms: Windows, macOS, Linux, Android, iOS
